# QSP Web frontend application

## Developers
### 💿 Install
Set up a githut personal access token from https://github.com/settings/personal-access-tokens/
Genereate a new Personal Access Token classic with at least the following scopes :

`read:packages`

Then edit your ~/.npmrc file to add the following lines:
```
//npm.pkg.github.com/:_authToken=ghp_xxxxxxxxxxxxxxxxxxxx
@ham-qsp:registry=https://npm.pkg.github.com
```

Set up your project using your preferred package manager. Use the corresponding command to install the dependencies:
`npm install`
